# Звук — Этап 3 (VW 1.9 TDI PD)

## Что улучшено

### AudioWorklet (`public/engine-processor.js`)

1. **Сильное сглаживание параметров**  
   RPM, load, boost, throttle и master gain сглаживаются экспоненциально. Это убирает щелчки и «застёжки» при резких изменениях.

2. **Дизельные импульсы сгорания**  
   - Короткий sharp attack (имитация PD clatter / knock)  
   - Тело импульса с экспоненциальным спадом  
   - Лёгкий imbalance по цилиндрам (оживляет звук)

3. **Механический слой**  
   Гармоники + суб-рокот, завязанный на обороты и нагрузку.

4. **Турбина**  
   Частота растёт с boost + rpm. Есть воздушный шум. Spool up медленнее, чем spool down.

5. **Overrun / сброс газа**  
   При резком падении throttle появляется короткий crackle/pop слой (затухает).

6. **Soft saturation (tanh)**  
   Защита от клиппинга и цифровой жёсткости.

7. **Лёгкий one-pole low-pass**  
   Убирает излишнюю «песчаность» на верхах.

### VehicleModel

- Throttle быстрее закрывается, чем открывается (естественный lift-off).
- Load сглажен.
- Turbo spool: медленный подъём, быстрый спад.

## Как тестировать

1. `npm run dev`
2. Start → SIM
3. Медленно поднимать throttle → слушать нарастание рокота и появление турбины.
4. Резко сбросить газ на средних/высоких оборотах → должны быть короткие crackles, без щелчков.
5. Держать постоянный throttle → звук стабильный, без дрожания высоты тона.

## Известные ограничения (v0.1.1)

- Пока нет отдельного слоя впуска.
- Нет записей стартера (пока синтетический STARTING).
- Характер всё ещё процедурный — не студийная запись PD.
- На очень слабых устройствах возможны редкие drop-outs (нужно будет мониторить buffer size).
