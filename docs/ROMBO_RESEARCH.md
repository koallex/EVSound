# Исследование приложения Rombo (getrombo.com/app/)

**Дата исследования:** 28 октября 2026  
**Метод:** Анализ официального сайта, FAQ, страницы дашбордов, прямое взаимодействие с приложением через браузер (скриншоты, DOM-инспекция, режим demo).  
**Ограничения исследования:**  
- Нет доступа к реальному автомобилю Tesla / GPS-движению.  
- Тестирование только в режиме Demo (виртуальный throttle/brake).  
- Аудиоконтекст в sandbox-окружении не воспроизводит звук (нет реального восприятия качества).  
- Поведение при реальном GPS, потере сигнала, переключении передач в движении — на основе документации и FAQ.  
**Статусы проверки:**  
- ✅ Подтверждено тестом (в браузере / DOM / визуально)  
- 📄 Подтверждено документацией сайта  
- ❓ Требует проверки в реальных условиях (автомобиль / GPS)

Rombo имеет **10 двигателей**, каждый со своей синтезированной моделью звука, коробкой передач и уникальной приборной панелью (светлая/тёмная тема).

|---------|---------------------|---------|----------------------|
| Black Rider V8 5.0 | Cross-plane V8, aggressive cam, lumpy idle, raspy, crackle, до 7200 rpm | 7-speed dual-clutch | 80s LED panel + scanner light, display moves with sound |
| Muscle V8 6.2 | Cross-plane V8, uneven burble | 6-speed | Round faces, chrome bezels, orange needles |
| V12 6.0 | Smooth high-revving silky scream | 8-speed | LED revs (amber→red), big digital speed |
| Track hatch 2.0T | Turbo four, louder pops + blow-off in Sport | 6-speed | Analogue rev arc, AUTO/SPORT |
| Flat-six 3.0 | Boxer 6, deep uneven note, rough idle | 7-speed | 1970s analogue speedo + rev counter + load gauge |
| Turbo inline-6 3.0 | Smooth metallic straight-six, twin-scroll turbo | 8-speed | Analog dials with fine needles |

| Hot hatch 2.0 | NA inline-4, eager to 7000 | 6-speed | Thin arcs, closest to Tesla look |

## 2. Структура основного экрана

**Подтверждено:** ✅ (скриншоты + DOM)

- Верхняя панель: индикатор GPS / Demo, кнопки Settings, Auto/Sport, Start/Stop.
- Центральная зона: приборная панель текущего профиля.
  - Цифровой спидометр (большой).
  - Индикатор передачи (P/R/N/D + текущая цифра).
  - Тахометр (дуга из точек / LED / стрелка в зависимости от профиля).
  - Trip, Load, Coast индикаторы (бары).
  - Дополнительные элементы профиля (сетка, scanner и т.д.).
- В режиме Demo справа: большие зоны Brake и Throttle + подсказка по клавиатуре.
- Нижние индикаторы: ENGINE / GPS / SPORT / DEMO / SHIFT / COAST, бары RPM и GPS.

Приборная панель занимает большую часть экрана и адаптируется под профиль.

## 3. Меню настроек и процесс выбора двигателя

**Подтверждено:** ✅

Настройки открываются иконкой (шестерёнка / settings-btn).

Вкладки:
- **Engine** — сетка из 10 плиток с названием + кратким описанием. Выбор мгновенный.
- **Video** — Light / Dark / Auto, единицы скорости (km/h / mph).
- **Sound** — уровни, extra sounds (например scanner noise).
- **Car** — Standard / Long Range / Performance (для согласования нагрузки виртуального двигателя с реальным Tesla).
- **Diagnostics** — экспорт GPS-trace, тест руля и т.д.

После выбора профиля дашборд и звуковая модель меняются сразу.

## 4. Процедура запуска и остановки

**Подтверждено:** ✅ (визуально) + 📄

1. Нажать **Start**.
2. Кнопка меняется на «Starting…».
3. Идёт последовательность запуска (cranking → catch).
4. После запуска кнопка становится Stop (предположительно).
5. При потере аудио (звонок, музыка) появляется «Tap to resume audio».

В sandbox звук не воспроизводился, но состояние «Starting…» подтверждалось.

Остановка — через Stop (не тестировалось полностью).

---

## 5. Поведение при изменении скорости

**Подтверждено:** 📄 + ✅ (в Demo)

- В Drive-режиме: скорость из Geolocation API (coords.speed или расчёт по позициям).
- GPS обновляется ~1 раз в секунду.
- Приложение сглаживает и предсказывает скорость вперёд, чтобы уменьшить задержку.
- В Demo: throttle pad управляет ускорением, brake — замедлением. Скорость растёт/падает плавно.

---

## 6. Реакция на ускорение и замедление

**Подтверждено:** 📄 + частично ✅

- При разгоне обороты растут согласно выбранной передаче и нагрузке.
- При сбросе газа — engine braking / overrun effects (pops, crackle в зависимости от профиля).
- В Sport режиме передачи удерживаются дольше, есть blip throttle при понижении.

---

## 7. Поведение виртуальных оборотов

**Подтверждено:** 📄 + ✅

- Обороты рассчитываются из скорости + текущей передачи + передаточных чисел + главной передачи.
- На холостом ходу (скорость ≈ 0) — idle.
- При постоянной скорости обороты стабильны (нет дрожания).
- Ограничитель оборотов присутствует (разный по профилям).

---

## 8. Особенности переключения передач

**Подтверждено:** 📄

- Автоматическая коробка с логикой как у настоящего автомата.
- Режим Auto / Sport.
- В Sport: более высокие точки переключения, blip на downshift.
- При переключении — кратковременное изменение оборотов и звука (без щелчков, т.к. синтез непрерывный).
- E-drive — одна передача, без Sport.

В Demo можно вручную (SHIFT), но основной режим — авто.

---

## 9. Работа GPS и разрешений браузера

**Подтверждено:** 📄 + ✅

- Запрос разрешения только при необходимости (после Start).
- Использует `navigator.geolocation`.
- Индикатор «GPS off» / качество сигнала.
- В Demo GPS не используется.

---

## 10. Поведение при потере GPS

**Подтверждено:** 📄

- Приложение не считает отсутствие GPS доказательством остановки.
- Предположительно удерживает последнюю скорость / плавно снижает обороты.
- Индикация потери сигнала.

Требует проверки в реальных условиях (❓).

---

## 11. Аудиозадержка и плавность переходов

**Подтверждено:** 📄

- Небольшая задержка из-за 1 Гц GPS (предсказание маскирует).
- Звук полностью синтезированный: каждый импульс сгорания вычисляется в реальном времени + модель выхлопа.
- Нет сэмплов → нет петель и щелчков на стыках.
- Плавные переходы громкости и параметров.

Качество в реальном автомобиле ❓ (требует теста).

## 12. Адаптация к полноэкранному режиму

**Подтверждено:** 📄

- Tesla browser **не позволяет** fullscreen во время движения.
- Можно открыть через YouTube-редирект для fullscreen на стоянке.
- Приложение рассчитано на обычный вид браузера Tesla.

---

## 13. Особенности запуска без автомобиля

**Подтверждено:** ✅

- URL `?demo=1` включает Demo-режим.
- Появляются большие зоны Throttle / Brake.
- Можно тестировать все профили, запуск, переключения без GPS.
- Работает на десктопе и (предположительно) на телефоне.

---

## 14. Выявленные ограничения и ошибки

**Из документации и наблюдений:**

- Нет доступа к педали газа реального автомобиля → обороты только от GPS-скорости.
- Нет fullscreen в движении.
- Приложение исчезает при включении задней передачи (ограничение браузера Tesla).
- Аудио может быть приостановлено системой автомобиля (звонок, медиа).
- GPS ~1 Гц → небольшая задержка.
- Зависит от версии браузера Tesla.
- Нет офлайн-режима (нужен интернет для первой загрузки).
- В sandbox: длительное «Starting…» (вероятно из-за отсутствия реального AudioContext resume или ресурсов).

**Не выявлено** критических JS-ошибок в консоли при базовом взаимодействии.

## 15. Перечень функций, которые следует реализовать в EVoice

На основе исследования и ТЗ:

### Обязательные (высокий приоритет)
1. Полностью процедурный / гибридный синтез звука (не один сэмпл с pitch-shift).
2. Многослойная модель: combustion pulses + intake + turbo + exhaust resonances + mechanical noise.
3. Состояния двигателя: OFF → STARTING (cranking) → IDLE → RUNNING → STOPPING.
4. Виртуальная трансмиссия (автомат + возможность Sport / manual).
5. Расчёт оборотов из скорости + передач + параметров профиля.
6. Два режима: Drive (GPS) + Simulation (throttle/brake pad + клавиатура).
7. Индивидуальные приборные панели для каждого профиля (разные layout, шкалы, стиль).
8. Плавное сглаживание всех параметров (скорость, обороты, нагрузка, громкость).
9. Корректная обработка потери GPS и паузы AudioContext.
10. Settings: выбор профиля, единицы, тема, громкость, диагностика.
11. Крупные touch-friendly элементы управления.
12. Сохранение последнего выбранного профиля (localStorage).

### Желательные
- Диагностический оверлей.
- Поддержка нескольких дизельных профилей с разным характером (не один pitch-shifted rumble).
- Прогрев / cold start (опционально).
- Extra sounds (стартер, переключения, blow-off только где уместно).
- Адаптация под автомобильные браузеры (не только Tesla).

### Чего избегать (на основе Rombo)
- Копирования дизайна, названий, аудио или алгоритмов.
- Зависимости от сервера для основного функционала.
- Hover-only интерфейса.
- Жёсткой привязки только к одному производителю автомобилей.

## Итог исследования

Rombo — отличный референс по UX и архитектуре браузерного engine-sound симулятора:  
чистый процедурный синтез, сильная дифференциация профилей через дашборды, аккуратная работа с GPS и ограничениями автомобильного браузера.

EVoice должен взять лучшие практики (состояния, слои звука, индивидуальные панели, demo-режим), но реализовать всё самостоятельно, с фокусом на дизельные двигатели (особенно VW 1.9 TDI PD) и европейские повседневные автомобили, актуальные для рынка Беларуси.

**Статус этапа 1:** Завершён.  
Следующий шаг — архитектурный план и прототип аудиодвижка.
